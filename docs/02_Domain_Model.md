# Domain Model

## Purpose

This document defines the business entities of the Laboratory Inventory
Management System independently of the user interface, database and
Excel files.

------------------------------------------------------------------------

# Core Domains

## Catalog

### Reagent

Commercial laboratory reagent managed by inventory.

### Protein

Conceptual protein produced by the laboratory.

### DNA Sample

DNA construct stored by the laboratory.

### Antibody

Laboratory antibody available for experiments.

------------------------------------------------------------------------

## Production

### Protein Expression

Represents one protein expression experiment.

**Produces:** one or more Pellets (Falcon tubes).

### Purification

Represents one purification process.

**Produces:** one or more Aliquots.

------------------------------------------------------------------------

## Inventory

### Pellet

Physical Falcon tube generated by an Expression.

### Aliquot

Physical Eppendorf tube generated by a Purification.

Each aliquot occupies one storage position.

------------------------------------------------------------------------

## Storage

### Freezer

### Rack

### Shelf

Only where applicable (Falcon racks).

### Box

### Position

Storage hierarchy:

Freezer → Rack → Shelf (optional) → Box → Position

------------------------------------------------------------------------

## Administration

### User

Roles:

-   Administrator
-   Researcher
-   Guest

### Purchase Order

Represents a reagent request and its lifecycle.

------------------------------------------------------------------------

## Cross-cutting

### Inventory Movement

Represents any inventory event.

Movement types:

-   Creation
-   Consumption
-   Transfer
-   Correction

------------------------------------------------------------------------

# Main Relationships

-   One Protein can have many Expressions.
-   One Expression produces many Pellets.
-   One Protein can have many Purifications.
-   One Purification produces many Aliquots.
-   One Box contains many Positions.
-   One Position stores at most one physical item.
-   One User can register many operations.
-   One Purchase Order may generate one Reagent.
-   Every inventory item has one current Location.
-   Every inventory item may have many Inventory Movements.

------------------------------------------------------------------------

# Business Rules (Initial)

1.  A Position cannot contain more than one physical item.
2.  A Box belongs to exactly one Rack.
3.  A Rack belongs to exactly one Freezer.
4.  Every Pellet originates from one Expression.
5.  Every Aliquot originates from one Purification.
6.  Inventory movements must be traceable.
7.  Excel files mirror the system but are not the internal domain model.
