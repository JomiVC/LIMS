# Project Roadmap

## Purpose

This roadmap defines the planned evolution of the Laboratory Information
Management System (LIMS).

------------------------------------------------------------------------

# Version 0.1 -- Project Foundation

-   Repository structure
-   Documentation
-   Streamlit application
-   Configuration
-   SQLite connection

------------------------------------------------------------------------

# Version 0.2 -- User Management

-   Login
-   User roles
-   Permission system

------------------------------------------------------------------------

# Version 0.3 -- Reagents

-   Inventory
-   Search
-   Create
-   Edit
-   Consumption
-   Purchase orders
-   Multi-location support

------------------------------------------------------------------------

# Version 0.4 -- Storage

-   Freezer visualization
-   Racks
-   Boxes
-   Positions
-   Occupancy map

------------------------------------------------------------------------

# Version 0.5 -- DNA

-   DNA inventory
-   Locations
-   Consumption
-   History

------------------------------------------------------------------------

# Version 0.6 -- Protein Expression

-   Pellet registration
-   Falcon storage
-   Consumption tracking

------------------------------------------------------------------------

# Version 0.7 -- Protein Purification

-   Purification batches
-   Aliquots
-   Consumption
-   History

------------------------------------------------------------------------

# Version 0.8 -- Excel Integration

-   Import
-   Export
-   Synchronization
-   Conflict resolution

------------------------------------------------------------------------

# Version 0.9 -- Quality

-   Logging
-   Testing
-   Performance improvements
-   Error handling
